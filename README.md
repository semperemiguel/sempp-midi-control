# SEMPP MIDI CONTROL

Instaladores de SEMPP MIDI CONTROL para macOS (10.15 o posterior, Intel y Apple Silicon).

La app comprueba este repositorio para avisar de nuevas versiones. Cada release incluye el instalador `.pkg` y un archivo `SHA256SUMS` con el que la app verifica la descarga antes de instalarla.

## Publicar una versión

1. Copia el instalador a `releases/SEMPP-MIDI-CONTROL-x.y.z.pkg`.
2. Actualiza `latest.json` con `version`, `pkg`, `sha256` y `notes`.
3. Haz push a `main`. La app lo detecta en la siguiente comprobación (cada 6 horas o con "Comprobar ahora").
