# SEMPP MIDI CONTROL

Este repositorio aloja los archivos de actualización de SEMPP MIDI CONTROL (macOS). La aplicación lo consulta para avisar de versiones nuevas: cada versión publicada lleva su instalador en `releases/` y su firma SHA-256 en `latest.json`, que la app verifica antes de instalar.

**La descarga pública aún no está disponible.**
